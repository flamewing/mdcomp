# Low-level header review

This review covers `stream_utils.hh`, `bitstream.hh`, `function_ref.hh`, `forge_span.hh`, `unreachable.hh`, `ignore_unused_variable_warning.hh`, `basic_decoder.hh`, `moduled_adaptor.hh`, `lzss.hh`, and `options_lib.hh`, including their current callers. It follows the endian review. The fixes retain the stream-based codec APIs; this is not the gated buffer refactor.

## Confirmed findings and fixes

| Priority | Area | Finding and resulting behavior |
| --- | --- | --- |
| High | Bit buffers | Full-width 32/64-bit writes shifted by the word width, and zero-bit reads could do the same. Zero-count operations now leave state unchanged; full-width operations avoid invalid shifts; excessive counts throw before changing state. |
| High | Bit buffers | Unmasked high bits in a short write could overwrite previously buffered bits. Writes now use only the requested low bits. Flushing clears the buffer for reuse. |
| High | Bit streams | Copied/moved stream wrappers retained function references to callback members of the original wrapper. Callback objects now live inside the bit buffers and copy their underlying stream pointers directly. |
| High | Exception propagation | Bit callback constructors ignored throwing copies/moves; output flush, raw-byte writes, LZSS I/O, allocating node helpers, and optimal parsing promised not to throw. Construction and forwarding now reflect the operations performed, and stream/allocation failures propagate. Count validation can itself throw. |
| High | LZSS fill | Rocket's 960-byte history initialization exceeded a 64-byte static vector, then treated the resulting exception as unreachable. Fill now emits bounded chunks and rejects negative lengths. Dictionary copies validate history distance and scratch capacity before accessing the stream. |
| High | ComperX | Refactor-era distance and length encoding/decoding disagreed with the shipped assembly implementation. RLE displacement zero and ordinary signed displacements now match the assembly jump-table representation. Hand-authored vectors exercise both forms independently of the encoder. |
| High | Rocket | The compressed-size field included the four-byte header, unlike master. It now counts the payload, excluding outer even-byte padding. Empty payload copying also no longer sets an artificial output failure. |
| High | CLI files | Opening an output alias of the input truncated the source before reading it. Encode/decode helpers now reject equivalent paths before opening the output. Crunch retains its existing buffered in-place behavior. |
| Medium | Rounding/padding | The rounding expression overflowed near integer limits, divided by zero, and mishandled negative values. Failed padding writes could loop forever. Rounding validates factors and representability; padding computes a finite count and reports seek/write failures. |
| Medium | Stream size | Scanning with `ignore()` reached EOF and could throw under an EOF/fail exception mask on valid input. Sizing now uses end seeks, restores the original position, and reports streams that cannot provide a size. |
| Medium | Raw bytes | Byte counts could narrow into `streamsize`, and reads admitted const/bool destinations. Helpers check count representability and require writable non-bool integral storage for reads. Container reserve is optional rather than an undeclared requirement. |
| Medium | Range utilities | Nested conversion called nonexistent `ranges::transform`; pipeline results lost references; constructor exception traits used reversed type/argument order; closure inheritance failed on Clang/MSVC. Nested conversion uses a transform view, references survive composition, and construction is portable. |
| Medium | Callable references | Call forwarding lost rvalue categories and prevented move-only arguments. Bound pointer deduction failed, and const-qualified bindings could read the wrong union alternative. Forwarding and pointer binding now preserve the actual stored type. Function-pointer variables store their target value. Required standard headers are included directly. |
| Medium | Span construction | Negative counts and unsigned narrowing could form invalid ranges before span construction. Invalid counts now throw, and pointer-plus-count construction supports null empty spans without advancing a null pointer. Actual storage validity remains a caller precondition. |
| Medium | Decoder wrappers | Format failures were ignored, module loops could make no progress, and preexisting destination bytes counted toward the module output target. Wrappers propagate failures, detect stalled output, and measure output relative to the starting position. Oversized 16-bit module headers are rejected. |
| Medium | Aligned allocation | Different allocator alignments compared equal through the inherited allocator interface. Equality now includes alignment, which must be a power of two and sufficient for the element type. |
| Medium | LZSS parameters | Multi-bit descriptor writes could put parameter bytes on the wrong side of a descriptor boundary. Generic writes also bypassed the parameter buffer, and packed-byte writing targeted the wrong API. Parameter ordering now follows individual descriptor transitions. |
| Medium | LZSS ownership/finalization | Owned literal vectors were copied inside a noexcept constructor. They are now moved. Explicit, idempotent `finish()` propagates final write errors; destructor fallback records bad stream state and avoids flushing while an exception is unwinding. Writes after finalization are rejected. |
| Medium | LZSS costs | Final costs rounded the entire bit cost rather than descriptor bits, missed empty-input terminators and exact-boundary dummy descriptors, and compared prefix-adjusted destinations against an unadjusted end. The cost calculation now handles these cases explicitly. |
| Medium | Enigma | Refactored run loops stopped at 15 words rather than the format's 16, increasing compressed size in the master comparison. Run bounds are restored; packet width stays at least one bit; empty input no longer dereferences an empty frequency map. |
| Medium | CLI options | Signed-minimum parsing failed after stripping the sign; trailing garbage reported an unknown error; print-end ignored its boolean flag; unknown options and false codec results were ignored. These conditions are now checked, and file helpers flush/check output before reporting success. |
| Low | Support headers | `unreachable.hh` could include standard-library declarations inside `utils` after feature-test macros were loaded. Standard headers are now included outside the namespace, with a consistent noexcept wrapper. The unused-variable helper is explicitly noexcept. |

## Validation

The normal suite contains 42 utility cases and nine codec cases. Compile-time assertions cover fixed-storage bit operations across 8/16/32/64-bit words, callable NTTP invocation, span counts, rounding, range-reference preservation, and relevant exception specifications. Separate header checks compile the callable header alone and the unreachable header after `<version>` in C++23 mode. Runtime bit cases use an independent per-bit oracle, including every count and starting offset for a 64-bit word, both bit orders, and early/late refill behavior.

Codec smoke cases cover the seven LZSS codecs with empty, small, patterned, and repetitive inputs. ComperX has hand-authored decoding/encoding vectors derived from `src/asm/ComperX_internal.asm`; the assembly was read but not executed as an oracle. Enigma has run-boundary and empty cases plus a shared-lineage master reference vector. These checks do not establish complete format-edge coverage.

The [master-binary comparison](../tests/references/README.md) also tests all ten implemented codecs against both the published Windows snapshot and a frozen current-master build, including the branch immediately before tests were introduced. Provenance, hashes, corpus scope, and results are recorded separately.

## Remaining review risks and follow-up

1. `find_optimal_parse` still creates a typed span over byte-owned storage. Alignment and granularity are checked, but alignment alone does not establish typed-object lifetime. Resolve this with explicit typed ownership or byte loads during the buffer migration; the current tests do not prove strict-aliasing/lifetime correctness.
2. The parser keeps one best cost per input position even though descriptor phase can affect terminal padding. The fixes above repair definite accounting errors, but global optimality still needs a phase-aware exhaustive oracle or a proof that the retained state is sufficient. This is an unresolved review risk, not a demonstrated counterexample.
3. Module decoding still buffers all remaining compressed input and accepts a final module that produces at least the declared size. Exact consumed-input reporting, overproduction rejection, and malformed-token execution budgets need codec-specific fixtures and the checked-buffer contract.
4. `function_ref` remains non-owning. Referenced callables, objects, and reference-valued results must outlive their use. Its C++20 invocability checks do not provide the later standard library's complete temporary-reference diagnostics. Object-pointer type erasure also limits constant evaluation before newer language support.
5. Bitstream templates still use the standard integral concepts; the earlier extended 128-bit support is currently confined to endian I/O. Extending bit operations to native/MSVC integer classes needs its own mask, intrinsic, and constexpr coverage.
6. The binary comparison currently exercises default basic CLI modes. Moduled/alternate options, malformed input, larger parameter boundaries, independent encoder provenance, and executed MC68000/Z80 oracles remain in the testing-framework plan. Passing the current matrix does not unblock the buffer refactor.
